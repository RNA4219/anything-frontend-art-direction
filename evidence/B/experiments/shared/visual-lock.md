# 比較用の視覚条件

両条件で以下を同じにする。既存Art Directionの判断を尊重し、操作フローの変更に必要な範囲で実装する。

| 項目 | 固定値・条件 |
|---|---|
| インク色 | `#172323` |
| 紙色 | `#f6f2e9` |
| アクセント | `#245b48` |
| 見出し | 明朝系。外部font読込みに依存せず `"Yu Mincho", "Hiragino Mincho ProN", serif` |
| 操作・本文 | sans-serif。`system-ui, sans-serif` |
| 画面内容 | tasks.mdの見出し、説明、名前、3項目を同一にする |
| 基本構成 | 同じページに予約と在庫取込みの2領域。各領域の中で入力→操作→結果を読む |
| 操作表示 | loading/error/successを文字で示す。内部phase名や検査情報は画面に表示しない |
| 幅 | 広幅1280px、狭幅390pxで操作する。固定幅で横スクロールを作らない |
| 装飾 | 配色、見出し書体、題材、背景、装飾を別方向へ再設計しない |

この固定値は比較条件であり、普遍的に最善の美的選択という主張ではない。
操作追加で文字量が変わる場合は、その変更をインタラクション責務として記録する。
